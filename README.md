# 🎗️ Breast Cancer Prediction using Machine Learning

### 👨‍💻 RogithKumar

> A Machine Learning project exploring different algorithms for predicting breast cancer diagnosis and medical features.

---

## 🧠 About the Project

This project uses **Machine Learning algorithms** to analyze breast cancer data and make predictions based on features such as:

* 📏 Mean Radius
* 🧩 Mean Texture
* 📐 Mean Perimeter
* 📊 Mean Area
* 🌊 Mean Smoothness
* 🎯 Diagnosis

---

## 🤖 Algorithms Used

| Algorithm               | Purpose                   |
| ----------------------- | ------------------------- |
| 📈 Linear Regression    | Predict `mean_area`       |
| 🎯 Logistic Regression  | Predict `diagnosis`       |
| 🌳 Decision Tree        | Predict `mean_smoothness` |
| 🌲 Random Forest        | Predict `mean_smoothness` |
| ⚡ SVM / SVR             | Predict `mean_smoothness` |
| 👥 KNN Regression       | Predict `mean_smoothness` |
| 🧮 Gaussian Naive Bayes | Predict `diagnosis`       |
